# 当前技能系统设计原则（阶段快照）

## 一句话结论
当前 3 个核心 skill + 5 个辅助 skill 构成思维流程链，但维护边界需要明确。

## 核心判断
1. need-extractor 负责还原需求
2. idea-expander 负责打开可能性，但输出量需控制
3. skill-maintainer 负责诊断跑偏，但不应鼓励技能膨胀

## 适用范围
适用于个人 skill 系统设计场景。

## 不适用范围
不适用于技术架构决策（如选数据库）。
