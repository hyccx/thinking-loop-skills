# Trigger Library — 12 Built-in Expansion Triggers

Each trigger is a distinct thinking operation. Selecting the right trigger(s) for the user's input is the core skill of using idea-expander.

## 1. dimension-scan — 维度扫描
**Purpose:** Scan a concept across structural, process, risk, authority, memory, anti-system, experience, and evolution dimensions.
**Trigger phrases:** "从不同维度看 / 还有哪些角度 / 我可能漏了什么 / scan dimensions"
**Use when:** User wants to see a concept from multiple analytical axes, or suspects they are missing a category of thinking.

## 2. perspective-shift — 视角切换
**Purpose:** View the concept from another role: user, maintainer, critic, future-self, Codex, Obsidian, skill-maintainer, beginner, executor, bystander.
**Trigger phrases:** "换个角度 / 如果我是 xxx / 从不同角色看 / perspective shift"
**Use when:** User is stuck in their own viewpoint; needs to see through someone else's eyes.

## 3. meta-question — 元问题生成
**Purpose:** Generate high-quality open-ended questions that continue to open up thinking.
**Trigger phrases:** "我该怎么继续问 / 怎么问才能打开思路 / 帮我生成问题 / better questions"
**Use when:** User needs better questions, not answers.

## 4. reverse-thinking — 反向思考
**Purpose:** Consider "what if we don't do this", "what if we do the opposite", "what if we remove it entirely".
**Trigger phrases:** "反过来想 / 如果不做这个呢 / 完全砍掉呢 / reverse / invert"
**Use when:** User is in forward-only mode; needs to examine the null hypothesis.

## 5. analogy-transfer — 类比迁移
**Purpose:** Use a complete external system (car, body, factory, city, ecosystem, game, law, OS, company, library) as a structural analogy to reveal blind spots in the current concept.
**Trigger phrases:** "能不能类比 / 像什么一样想 / 用整体结构来反推 / analogy"
**Use when:** User is inside the problem; needs an external frame to reveal hidden structure.

## 6. gap-scan — 缺口扫描
**Purpose:** Scan the current system for missing capabilities, rules, modes, handoffs, tests, memory, or permission boundaries.
**Trigger phrases:** "还缺什么 / 查漏补缺 / 哪个环节没覆盖 / gap / missing"
**Use when:** User has a partially-built system and wants to find what's missing.

## 7. risk-preplay — 风险预演
**Purpose:** Simulate how an idea will fail, bloat, overstep authority, or increase maintenance cost.
**Trigger phrases:** "会不会出问题 / 以后会不会复杂 / 最可能失控在哪里 / risk / worst case"
**Use when:** User is excited about an idea but hasn't considered failure modes.

## 8. future-retrospective — 未来回看
**Purpose:** Stand at three-months-later and review the current design as a past decision.
**Trigger phrases:** "以后怎么看 / 未来的我会不会看不懂 / 长期会怎样 / retrospective"
**Use when:** User is deep in design and has lost time-perspective.

## 9. minimal-version — 极简化
**Purpose:** Compress the idea into the smallest viable version that still produces value.
**Trigger phrases:** "最小版本是什么 / 能不能简单点 / 只保留核心呢 / minimal / MVP"
**Use when:** User is over-building and needs a forced constraint.

## 10. recombination — 组合重构
**Purpose:** Judge whether a new capability should merge into an existing skill, become a mode, reference, test, or a new skill.
**Trigger phrases:** "应该新建 skill 吗 / 能不能合并 / 应该放哪里 / recombine"
**Use when:** User wants to add something but isn't sure where it belongs.

## 11. frame-break — 边界突破
**Purpose:** Step outside the current framing and adopt a fundamentally different underlying structure.
**Trigger phrases:** "跳出这个框架 / 别沿着现在方向想 / 有没有更底层的看法 / frame break"
**Use when:** User is locked into a particular paradigm.

## 12. anti-system-check — 反系统检查
**Purpose:** Determine whether the current problem should NOT be systematized further; i.e., it should stay as a concept, note, or one-off, not become a skill, mode, or structured workflow.
**Trigger phrases:** "是不是没必要系统化 / 是不是想复杂了 / 是不是不该建 skill / anti-system"
**Use when:** User reflexively tries to build a system for everything.

## Selection Guide

- Prefer dimension-scan and perspective-shift as default pair for unknown-inputs.
- Always pair recombination with anti-system-check when the user asks about skill creation.
- If risk-preplay triggers, also consider future-retrospective — they often reveal the same blind spots from different angles.
- If minimal-version triggers, do NOT also trigger deep-expansion — they are contradictory.
