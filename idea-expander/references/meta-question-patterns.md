# Meta-Question Patterns — Generative Question Templates

Use these question templates when in meta-question mode. Each question type opens a different kind of thinking.

## System Structure Questions
- 如果它是一个系统，缺什么部件？ (If this is a system, what parts are missing?)
- 这个系统的核心部件是什么？可有可无的部件是什么？ (What is core vs optional?)

## Failure Simulation Questions
- 如果它会失控，最可能在哪里？ (If it goes wrong, where will it fail first?)
- 什么情况下它会变得不可维护？ (Under what conditions does it become unmaintainable?)

## Time-Based Questions
- 如果三个月后回看，什么会变成负担？ (Looking back in 3 months, what will feel like a burden?)
- 如果现在不做，一个月后你会庆幸还是后悔？ (If you don't do it now, will you be relieved or regretful in a month?)

## Inversion Questions
- 如果不做它，会损失什么？ (If you don't build it, what do you actually lose?)
- 如果只做最小版本，保留什么？砍掉什么？ (If minimal, what stays? What gets cut?)

## Placement Questions
- 如果不新建 skill，它能放进哪里？ (If you don't create a new skill, where does it live?)
- 它能作为已有技能的一个 mode 吗？一个 reference？一个 test？ (Could it be a mode, a reference, or a test in an existing skill?)

## Proportionality Questions
- 如果它只是一次性想法，是否不该系统化？ (If it's just a one-shot thought, should it even be systematized?)
- 做它需要多少精力？值得吗？ (How much effort does it take? Is it worth it?)

## Critique Questions
- 如果从反对者角度看，它哪里站不住？ (From the critic's angle, where does this fall apart?)
- 假设你必须在一分钟内说服一个 skeptical 同事，你会怎么说？ (How would you sell this to a skeptical coworker in 60 seconds?)

## Usage
- Pick 2-3 questions that best match the user's domain and tone.
- Frame the question in the user's language, do not read verbatim from this library.
- If the user seems stuck on one meta-question, follow up with a different type entirely (e.g., switch from structure to critique).
